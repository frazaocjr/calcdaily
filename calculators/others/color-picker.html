Choosing and Converting Color Values

Select a color with the picker to view its value in common digital color formats, including HEX, RGB, HSL, and CMYK. HEX and RGB are widely used in web interfaces, while HSL expresses hue, saturation, and lightness in a way that can be convenient when adjusting a color.

Screen color is not print proofing

Displays differ in calibration, brightness, and color gamut. The CMYK value is a mathematical conversion and may not match a print shop's output profile or ink behavior. Always review final colors in the actual device or production workflow.

Worked example

For example, HEX #3366CC corresponds to RGB values 51, 102, and 204. Displayed digital values are useful for screen design; they do not replace proofing on a calibrated display or printer.

Why does the same color have several codes?

HEX, RGB and HSL describe colour using different representations of the same selection. CMYK values are only approximate conversions for design reference and may not match a particular printer or colour profile.
