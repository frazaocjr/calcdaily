Binary Converter

Convert whole numbers between binary, decimal, octal, and hexadecimal number systems.

Converted Bases

Decimal (10): 42
Binary (2): 101010
Octal (8): 52
Hexadecimal (16): 2A

How Number-Base Conversion Works

The converter reads the entered integer in the selected source base, interprets it as a numeric value, and displays that value in decimal, binary (base 2), octal (base 8), and hexadecimal (base 16). The same integer is represented with different digit systems; its mathematical value does not change.

Input limitations

This tool is intended for whole-number conversion, not fractional values or floating-point representations. Use digits and letters that are valid for the selected base. The tool uses integer arithmetic and does not accept fractional values. Extremely long inputs may still be impractical to process in a browser.

Worked example
