How the Number Draw Works

The generator draws whole numbers between the inclusive minimum and maximum values. With repetition enabled, each draw is made independently and the same number may appear more than once. With repetition disabled, the tool collects unique values so a number cannot be selected twice in the same set.

Randomness and appropriate use

This page uses the browser's Math.random() pseudorandom generator. It is suitable for casual examples, games, and informal choices, but it is not a cryptographic random source and is not an audited drawing system. Do not rely on it for security, regulated lotteries, or high-stakes prize selection.

For example, a range from 1 to 10 contains ten possible integers because both endpoints are included. With duplicates disabled, the requested quantity cannot exceed the number of available integers.

What does no-repeat mode mean?

With repeat mode off, a number is selected at most once within the requested inclusive range for that draw. You cannot request more unique integers than the range contains. Do not assume this page provides certified lottery or cryptographic draws.
