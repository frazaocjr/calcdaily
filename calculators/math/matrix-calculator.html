Which Matrix Operations Are Supported?

This page operates on two 2 × 2 matrices. Select addition to add corresponding entries, subtraction to subtract corresponding entries, or multiplication to calculate each result entry from the row of the first matrix and the column of the second matrix. The displayed result updates as the input cells change.

Scope of this tool

This version does not calculate determinants, inverses, or transposes. Matrix multiplication is not element-by-element multiplication; it follows row-by-column multiplication. Keep that distinction in mind when checking homework or working through a linear-algebra example.

Example and limitations

For addition and subtraction, each output cell combines the values in the same position. Matrix multiplication uses row-by-column products. The tool is limited to 2 × 2 matrices and does not calculate determinants or inverses.
