Three Common Percentage Questions

The first panel calculates a percentage of a value by multiplying the value by the percentage divided by 100. The second divides a part by a total and converts the ratio to a percentage. The third compares a starting value with an ending value and reports the size and direction of the percentage change relative to the starting value.

Choose the correct starting value

Percentage change is undefined when the starting value is zero. A percentage increase or decrease is not the same as a percentage-point change, which is used when comparing two percentages.

Example and limitations

For a percentage-of-value question, 20% of 150 is 30. Percentage change compares the difference with the starting value, so the direction and reference value matter when interpreting an increase or decrease.

How are percentage change and percent of a value different?

To find 20% of 50, calculate 0.20 × 50 = 10. To find a change from 50 to 60, divide the difference by the original value: (60 − 50) ÷ 50 × 100 = 20%. The denominator matters when comparing values.
